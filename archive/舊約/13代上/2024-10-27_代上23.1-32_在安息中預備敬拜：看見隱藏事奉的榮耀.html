一、新季節的轉變：從「扛抬」到「安息」的呼召

Scripture Context

「大衛年紀老邁，日子滿足，就立他兒子所羅門作以色列的王... 大衛說：『耶和華─以色列的神已經使他的百姓平安，他永遠住在耶路撒冷。利未人不必再擡帳幕和其中所用的一切器皿了。』」

Keyword
安息 / 平安
נוּחַ / Nuach
Question

當事奉的環境或形式改變時，我們如何調整自己的心態來繼續服事神？

深入解析

利未人過去幾百年來的驕傲與核心任務就是「扛抬約櫃與會幕」。如今因為神賜下安息，這個任務消失了。這提醒我們，服事的形式會隨著神帶領的季節而改變。我們不能死守「過去的輝煌」，而必須敏銳於神當下的心意。

例證 / 故事

退休牧師不再是講台上的領袖，而是默默在門口發週報的同工。他說：「以前神要我拿麥克風，現在神要我拿週報，主人的命令變了，但僕人的心沒有變。」

「事奉不是為了建立我們的履歷，而是為了回應神的恩典。」 — 提摩太·凱勒

Keyword
事務 / 服事
עֲבֹדָה / Avodah
Question

如何看待那些瑣碎、不顯眼的「日常服事」的價值？

二、神聖的日常：看見「隱藏事奉」的永恆價值

Scripture Context

「他們的職任是服事亞倫的子孫... 潔淨一切聖物... 管理陳設餅，素祭的細麵，或用烤盤烤的，又管理各樣的升斗尺度。」

深入解析

Avodah 同時包含了「工作」與「敬拜」。對利未人而言，烤餅、量尺寸、打掃等勞動，在神眼中就是神聖的敬拜。沒有這些「日常的預備」，祭司就無法獻祭，敬拜就無法進行。在神的國度裡，沒有所謂「卑微的服事」，只有「卑微的心態」。

例證 / 故事

十七世紀的勞倫斯弟兄（Brother Lawrence）將洗碗與煮飯變成了經歷神同在的至高敬拜，他說：「我翻轉煎鍋裡的一個煎餅，也是出於愛神的緣故。」

「隱藏是屬靈生命的基石。當我們願意在隱藏中服事，我們便開始脫離世界的掌聲。」 — 盧雲

三、不間斷的祭壇：每日「早晚站立」的敬拜者

Scripture Context

「每日早晚，站立稱謝讚美耶和華... 按數照例，將燔祭常常獻給耶和華。又看守會幕和聖所...」

Keyword
站立
עָמַד / Amad
Question

忙碌的服事與生活中，如何保持「每日早晚」的敬拜節奏？

深入解析

「站立」代表一種「準備好、堅定不移、侍立在君王面前」的態度。早晚的站立，代表一天從神開始，也由神結束。這提醒我們，服事不能取代敬拜；事工再忙，也不能省略每日在神面前的站立。敬拜是所有服事的核心動力。

例證 / 故事

一位科技業信徒規定：早上收信前站立默禱兩分鐘；晚上下班關車門前讚美神。這個「早晚站立」成為他抵禦焦慮、保持屬靈敏銳度的力量。

「早晨的靜默是為著對抗一天的喧囂，夜晚的讚美則是安息的確據。」 — 潘霍華

講章文稿

代上23:1-32：在安息中預備敬拜：看見隱藏事奉的榮耀

SERMON TRANSCRIPT

弟兄姐妹們，平安。當我們讀到歷代志上第23章時，可能會覺得這是一份枯燥的「人事組織名單」。此時大衛已經年邁，他正在為所羅門建殿做最後的預備。聖殿連一根柱子都還沒蓋好，大衛卻已經把利未人的班次、工作都安排妥當了。在這段看似繁雜的經文中，其實隱藏著極深的屬靈光景。

一、 新季節的轉變：從「扛抬」到「安息」的呼召

幾百年來，利未人最神聖的任務就是在曠野中扛抬會幕與約櫃。那是他們的身分認同，是他們的榮耀。但神說：「現在季節改變了。」神賜下了安息 (Nuach)。因為安息，利未人不再需要漂泊。

「事奉不是為了建立我們的履歷，而是為了回應神的恩典。」

二、 神聖的日常：看見「隱藏事奉」的永恆價值

烤餅、打掃、量度量衡，在神眼中就是服事/敬拜 (Avodah)。這字同時包含「勞動」與「敬拜」的意思。在神的國度裡，沒有所謂「卑微的服事」，只有「卑微的心態」。正如盧雲所說：「隱藏是屬靈生命的基石。當我們願意在隱藏中服事，我們便開始脫離世界的掌聲，真正進入神的同在裡。」

三、 不間斷的祭壇：每日「早晚站立」的敬拜者

「每日早晚，站立稱謝讚美耶和華。」（代上 23:30）

這就是我們今天的金句。「站立」是一種準備好、堅定且尊崇的姿態。潘霍華教導我們：「早晨的靜默是為著對抗一天的喧囂而獻給上帝的祭，夜晚的讚美則是安息在神恩典中的確確據。」

願我們都能在轉變中順服，在隱藏事務中看見神聖價值，無論多忙，都能堅持早晚站立讚美！

— 傅士德 (Richard Foster) 《屬靈操練禮讚》
