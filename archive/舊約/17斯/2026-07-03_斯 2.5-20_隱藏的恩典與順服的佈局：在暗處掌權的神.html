斯 2:5-20:隱藏的恩典與順服的佈局：在暗處掌權的神

「王愛以斯帖過於愛眾女，她在王眼前蒙寵愛比眾處女更甚。王就把王后的冠冕戴在她頭上，立她為王后，代替瓦實提。」[cite: 1]
禱告詞

全能的父神，當我們處在看似沒有祢名字出現的環境中，求祢開啟我們屬靈的眼睛，看見祢隱藏的恩典與佈局。[cite: 1] 主啊，教導我們像以斯帖一樣，在世俗的挑戰中保持內在的靜謐與順服，不張狂、不妄求；也教導我們像末底改一樣，忠心於祢所託付的責任。[cite: 1] 無論我們被擺放在何等位階，願我們都不忘記自己的屬靈身分，成為祢榮耀的器皿。[cite: 1] 奉主耶穌基督的名求，阿們。[cite: 1]

歷史、人文、政治環境背景分析

《以斯帖記》的時代背景設定在主前五世紀的波斯帝國（亞哈隨魯王，即薛西斯一世，約主前486-465年在位）。[cite: 1] 當時許多猶太人雖已獲准回歸耶路撒冷，但仍有大量猶太人選擇留在波斯的政治中心書珊城。[cite: 1] 這是一個被擄與寄居的處境，猶太人面臨著身分認同的危機與被同化的壓力。[cite: 1] 波斯宮廷充滿了極權統治、父權主義與後宮爭鬥，人的生命在專制君王的一念之間。[cite: 1] 在整卷《以斯帖記》中，從未提及「神」的名字，這正反映了當時猶太人在異教帝國中「神彷彿隱藏」的真實處境，但也深刻地襯托出：即使在最世俗、最黑暗的政治權力中心，神依然在幕後掌權，透過平凡人的順服與環境的巧合，推動祂拯救子民的計畫。[cite: 1]

猶太文學結構分析：交錯配列（Chiasmus）

本段經文運用了猶太文學經典的對稱與交錯配列結構（A-B-C-D-C'-B'-A'），突顯了神在人事變遷中的精心編排：[cite: 1]

  • A (2:5-7)：末底改的背景與他對以斯帖的收養與教導。[cite: 1]
  • B (2:8-10)：以斯帖被送入宮中，蒙希該喜悅，但隱藏猶太身分。[cite: 1]
  • C (2:11)：末底改每日在女院前行走，關心以斯帖的平安。[cite: 1]
  • D (2:12-14)：核心轉折：眾女子預備朝見王的規矩與過程。[cite: 1]
  • C' (2:15-16)：以斯帖按次序進去見王（不妄求，呈現內在的平安與預備）。[cite: 1]
  • B' (2:17-18)：以斯帖蒙王寵愛，被立為王后，大排筵席。[cite: 1]
  • A' (2:19-20)：末底改坐在朝門，以斯帖位居高位仍順服末底改的教導（維持隱藏的身分）。[cite: 1]

此結構將「以斯帖的預備與不妄求」(D) 放在中心，首尾呼應了末底改的忠心與以斯帖的順服，顯示出屬靈品格在世俗宮廷中的關鍵作用。[cite: 1]

第一段：被擄的孤女與忠心的養父——隱藏身分的恩典

經文範圍：斯 2:5-11[cite: 1]

書珊城有一個猶大人，名叫末底改... 末底改天天在女院前邊行走，要知道以斯帖平安不平安，並後事如何。[cite: 1]

關鍵原文：

  • 撫養 (אמן / aman)：原文有堅固、建立、忠心之意（阿們的詞源）。[cite: 1] 末底改不僅是提供食物，更是「堅固」了以斯帖的信仰與品格。[cite: 1]
  • 恩待 (חסד / hesed)：通常指神立約的慈愛與恩典。[cite: 1] 此處用在太監希該對以斯帖的態度，暗示這是神在背後施展的恩惠。[cite: 1]

關鍵問題：為什麼末底改要以斯帖隱藏自己的猶太身分？這是否是不敬虔的妥協？[cite: 1]

解析：在但以理的時代，信仰需要公開的抗爭；但在以斯帖的處境中，神允許他們在特定的季節「隱藏」。[cite: 1] 這不是懦弱的妥協，而是神戰略性的佈局。[cite: 1] 在充滿敵意的世俗環境中，有時我們需要智慧的隱藏，先藉著卓越的品格與工作態度贏得信任，等待神所命定的發言時機。[cite: 1]

例證/故事：在冷戰時期的東歐，有一位名叫理查·魏恩布蘭德（Richard Wurmbrand）的牧師，他在地下教會服事時，許多信徒在共產黨政府的體制內擔任要職。[cite: 1] 他們並未立刻四處張揚自己的信仰，而是隱藏身分，在暗中保護其他信徒，並在最關鍵的時刻發揮了極大的影響力。[cite: 1] 這正如以斯帖在波斯宮廷中的隱藏，是為了成就更大的拯救。[cite: 1]

名言佳句：潘霍華 (Dietrich Bonhoeffer)：「基督徒的生命不是從世界中撤退，而是在世界的中心活出隱藏的基督生命。」[cite: 1]

第二段：宮廷的預備與內在的靜謐——順服權柄的智慧

經文範圍：斯 2:12-16[cite: 1]

眾女子照例先潔淨身體十二個月... 除了掌管女子的太監希該所派定給她的，她別無所求。凡看見以斯帖的都喜悅她。[cite: 1]

關鍵原文：

  • 別無所求 (לא בקשה דבר / lo bakesh davar)：字面意思是「沒有尋求任何事物」。[cite: 1] 在一個充滿競爭、所有女孩都想盡辦法用奢華飾品裝扮自己以取悅君王的環境裡，以斯帖選擇完全放棄自我主張，順服太監希該的專業安排。[cite: 1]

關鍵問題：在一個強調「自我行銷」與「爭競」的世界裡，以斯帖的「別無所求」為何反而讓她脫穎而出？[cite: 1]

解析：以斯帖的「別無所求」反映出她內在極大的安全感與靜謐。[cite: 1] 她沒有被焦慮和慾望驅使，而是展現出對權柄的順服。[cite: 1] 當其他女子用外在的物質來定義自己時，以斯帖的從容與謙卑，反而成為充滿算計的後宮中最清新的氣質。[cite: 1] 這是屬靈品格在世俗職場中極大的得勝力。[cite: 1]

例證/故事：被譽為「中國內地會」創辦人的戴德生，初到中國時，並未帶著西方優越感大肆宣揚自己的不同，反而順服了當地的文化，剃了髮辮、穿上中國服飾。[cite: 1] 他沒有要求特殊的待遇或外在的光環，這種「別無所求」與謙卑的態度，最終贏得了無數中國人的心。[cite: 1]

名言佳句：慕安德烈 (Andrew Murray)：「謙卑不是一種我們要帶到神面前的東西，也不是祂要賜下的東西；謙卑是意識到自己一無所有，並真正在神面前退去，讓神成為一切。」[cite: 1]

第三段：王后的冠冕與不變的本心——高陞後的考驗

經文範圍：斯 2:17-20[cite: 1]

王愛以斯帖過於愛眾女... 以斯帖照著末底改所囑咐的，還沒有將籍貫宗族告訴人；因為以斯帖遵管教，和在末底改手下從前一樣。[cite: 1]

關鍵原文：

  • 寵愛 (חן וחסד / hen va-hesed)：恩典與慈愛。[cite: 1] 這裡同時使用了兩個詞，表示極大的恩寵。這不僅是王個人的喜好，更是神至高主權的介入。[cite: 1]
  • 遵管教 (מאמר תעשה / ma'amar ta'aseh)：字面意思是「照著所吩咐的去行」。[cite: 1] 以斯帖成了帝國最有權勢的女人，卻依然順服末底改。[cite: 1]

關鍵問題：當一個人獲得極大的權力與地位時，最容易發生什麼事？以斯帖是如何克服這種試探的？[cite: 1]

解析：權力是最好的照妖鏡，常常使人驕傲、忘本。[cite: 1] 以斯帖從一個被擄的孤女躍昇為波斯帝國的王后，這是極大的權力與財富。[cite: 1] 但第20節是全段的點睛之筆：「以斯帖遵管教，和在末底改手下從前一樣。」[cite: 1] 她沒有因為戴上王后的冠冕就拋棄了屬靈的權柄與本心。[cite: 1] 她知道自己的根基在哪裡。[cite: 1]

例證/故事：歷史上著名的英國講道王子司布真（Charles Spurgeon），在20多歲時就聲名大噪，成千上萬的人湧入教會聽他講道。[cite: 1] 然而，當他擁有極大影響力時，他依然保持著如孩童般對神的順服，並順服於神的話語。[cite: 1] 他曾說，如果神呼召你成為宣教士，就不要降格去當國王。[cite: 1] 高位沒有改變他對屬靈原則的堅持。[cite: 1]

名言佳句：提摩太·凱勒 (Timothy Keller)：「如果你將自己的身分建立在成功上，當你成功時，你會變得驕傲與傲慢；如果你將身分建立在神的恩典上，成功就不會讓你衝昏頭，失敗也不會將你摧毀。」[cite: 1]

應用方向
  • 在看不見神的日子裡，相信祂隱藏的恩手：我們常常覺得生活平庸、甚至處於劣勢（如以斯帖是孤女與亡國奴），但神往往在最平凡甚至充滿限制的環境中，鋪排祂恩典的佈局。[cite: 1]
  • 以內在的安全感取代外在的爭競：學習以斯帖的「別無所求」。[cite: 1] 在職場與生活中，不要被世俗的焦慮與物質的比較所牽引，用忠心與順服來面對我們的「希該」（主管/環境）。[cite: 1]
  • 不論位高權重，保持屬靈的順服與受教：當神提升我們的地位、財富或影響力時，必須像以斯帖一樣「與從前一樣」順服屬靈的遮蓋與神的真理，因為權位是為了神國的旨意，而非滿足私慾。[cite: 1]

3個關鍵字作為結論

  • 隱藏 (Hiddenness)[cite: 1]
  • 順服 (Submission)[cite: 1]
  • 恩寵 (Favor)[cite: 1]

回應與實踐行動

  • 檢視生命中的「隱藏時期」：寫下目前生活中看似沒有出路或平凡的領域，禱告求神賜下眼光，看見這可能是神正在預備你的階段，並選擇在其中忠心。[cite: 1]
  • 操練「別無所求」的簡樸與順服：在本週的職場或人際互動中，刻意放下一次「為自己爭取利益或掌聲」的機會，選擇順服環境的安排與權柄，將結果交託給神。[cite: 1]
  • 重拾對屬靈權柄的敬重：如果你最近在事業、學業上有所成就，請刻意找一位屬靈長輩（你的「末底改」）交通，並虛心接受他的建議與指引，保持受教的心。[cite: 1]
講章文稿

斯 2:5-20：隱藏的恩典與順服的佈局：在暗處掌權的神[cite: 1]

各位弟兄姊妹，平安。[cite: 1] 今天我們要進入一段充滿戲劇張力的經文——《以斯帖記》第二章5到20節。[cite: 1] 整卷以斯帖記有一個非常奇特的現象，那就是從頭到尾沒有出現過一次「神」的名字。[cite: 1] 但正是這種「神的隱藏」，最深刻地描繪了我們現今在世俗社會中的真實光景。[cite: 1] 有時候，我們看不見神蹟，聽不見先知的聲音，我們只看到世俗的政治、職場的爭鬥、以及無可奈何的環境。[cite: 1] 但今天的信息要告訴我們：在暗處掌權的神，正透過隱藏的恩典與人的順服，進行祂偉大的佈局。[cite: 1]

首先，我們來看被擄的孤女與忠心的養父——隱藏身分的恩典。[cite: 1]

經文告訴我們，末底改是一個被擄亡國的猶太人，他收養了失去雙親的堂妹以斯帖。[cite: 1] 以斯帖被強徵入宮，面對這不可抗拒的命運，末底改卻做了一個特別的決定：他要求以斯帖「隱藏」猶太人的身分。[cite: 1] 弟兄姊妹，我們常常以為信仰就是要大張旗鼓，但在特定的歷史處境與黑暗中，神允許祂的兒女成為「隱藏的種子」。[cite: 1] 末底改對以斯帖的「撫養」（原文有堅固、忠心之意），不僅是給她飯吃，更是把信仰的根基深深紮在她心裡。[cite: 1] 在世俗中，我們不需要總是急於證明自己的敬虔，而是要在暗處累積品格，等候神發出的信號。[cite: 1]

接著，我們看到宮廷的預備與內在的靜謐——順服權柄的智慧。[cite: 1]

以斯帖進入了女院。你可以想像那個畫面：全帝國最美麗的女子聚集在一起，每個人都想盡辦法用最名貴的香料、最華麗的服飾來打扮自己，因為這是一場決定命運的殘酷選美。[cite: 1] 但經文在第15節記載了一個極為震撼的細節：「除了掌管女子的太監希該所派定給她的，她別無所求。」[cite: 1]

以斯帖在焦慮與充滿爭競的環境中，展現了極大的內在靜謐。[cite: 1] 她的「別無所求」，不是因為她愚笨，而是因為她有著不被世俗慾望牽著鼻子走的安全感。[cite: 1] 她順服了太監希該的專業與權柄。[cite: 1] 這提醒我們，在職場上，我們不需要不擇手段地去爭奪上位，當我們帶著屬神的平安與謙卑，順服環境中神所設立的權柄時，神親自會把那份屬天的「恩寵」（hesed）加在我們身上。[cite: 1]

最後，我們來到王后的冠冕與不變的本心——高陞後的考驗。[cite: 1]

我們一起來讀今天的【金句】斯 2:17：「王愛以斯帖過於愛眾女，她在王眼前蒙寵愛比眾處女更甚。王就把王后的冠冕戴在她頭上，立她為王后，代替瓦實提。」[cite: 1]

以斯帖登上了波斯帝國的后座。[cite: 1] 一個被擄的孤女，如今成了最有權勢的女人。[cite: 1] 歷史上，有多少人一有了權力、財富，就忘記了自己是誰，忘記了神的恩典。[cite: 1] 但第20節卻寫道：「以斯帖遵管教，和在末底改手下從前一樣。」[cite: 1]

這是何等美麗的屬靈品格！冠冕改變了她的地位，卻沒有改變她的本心。[cite: 1] 她依然順服末底改的教導。[cite: 1] 弟兄姊妹，當神提升你的時候，當你在事業上、在社會上獲得成功的時候，你是否還能像從前那個單純仰望神的人一樣，順服屬靈的權柄與真理？[cite: 1]

在沒有神名字出現的《以斯帖記》裡，處處都是神的指紋。[cite: 1] 神透過末底改的忠心、以斯帖的別無所求與謙卑順服，把一顆棋子精準地放在了波斯帝國的核心，為日後拯救整個猶太民族埋下了伏筆。[cite: 1] 願我們在看似平凡、充滿限制的世俗生活中，都能活出這種隱藏的恩典與順服的生命。[cite: 1] 阿們。[cite: 1]
