衝動的宣告與蒙蔽的領袖
跨越屬肉體的熱心

1 Samuel 14:24-52

「百姓對掃羅說：『約拿單在以色列人中這樣大行拯救，豈可叫他死呢？斷乎不可！...因為他今日與神一同做事。』」

開聲禱告

主阿，我們來到祢面前，承認我們常常像掃羅一樣，用屬肉體的熱心和衝動的決定來代替對祢真實的順服。求祢赦免我們在事奉中不自覺產生的驕傲與律法主義，不要讓我們看似敬虔的宣告成為別人的轄制與絆腳石。賜給我們約拿單那樣明亮的眼睛與自由的心靈，看見祢的恩典，並願意與祢同工。求聖靈引導我們，不單注重外在的儀式，更看重內心的真理與憐憫。奉主耶穌基督的名求，阿們。

01

瞎眼的熱心：被轄制的起誓

【引用經文】 (14:24-30) 掃羅叫百姓起誓說：「凡不等到晚上向敵人報了仇吃什麼的，必受咒詛。」...約拿單說：「我父親連累你們了。你看，我嘗了這點蜜，眼睛就明亮了。」

Key Original

起誓 / 咒詛 (אָלָה, 'alah)

Core Problem

為什麼看似敬虔的禁食宣告，反而成為全軍的絆腳石？

解析回答

當屬靈操練脫離了神的心意，淪為領袖滿足個人野心或面子的工具時，就會變成毫無恩典的律法主義。這不僅無法帶來力量，反而使人在爭戰中「極其困乏」。

「宗教是：『我順服，所以我被接受。』福音是：『我被接受，所以我順服。』」—— 提摩太·凱勒
02

失控的惡果：急躁帶來的妥協

【引用經文】 (14:31-35) 那日，以色列人擊殺非利士人...百姓甚是疲乏，就急忙將所奪的牛羊和牛犢宰於地上，肉還帶著血就吃了。

Key Original

急忙 (עִיט, 'iyt)

Core Problem

為什麼極端的律法主義最終往往會導致嚴重的犯罪？

解析回答

當合法的需求被不合理的宗教規定壓抑到極點時，反彈的力量會使人失去對基本真理的持守。人的規條往往會把人推向違背神旨意的深淵。

「人的律法使人成為奴隸，但上帝的恩典使人得自由。」—— 潘霍華
03

沉寂的天上：當神不再說話

【引用經文】 (14:36-42) 掃羅求問神說：「我下去追趕非利士人可以不可以？你將他們交在以色列人手裡不交？」這日神沒有回答他。

Key Original

求問 (שָׁאַל, sha'al)

Core Problem

當我們熱心服事時，上帝為何有時會保持沉默？

解析回答

神不回答掃羅，是因為掃羅的生命中存在著未處理的破口與盲點。當我們的心被自大與自義蒙蔽，只想要神為我們的計畫背書時，神往往會用沉默來警告我們。

「我們常常不是在尋求神的旨意，我們只是在尋求神對我們自己旨意的批准。」—— 陶恕
04

恩典的代求：與神同工的轉機

【引用經文】 (14:43-52) 百姓對掃羅說：「約拿單在以色列人中這樣大行拯救，豈可叫他死呢？斷乎不可！...因為他今日與神一同做事。」

Key Original

救 / 拯救 (פָּדָה, padah)

Core Problem

真正的屬靈領袖，是堅持自己的面子，還是順服神在別人身上的工作？

解析回答

屬靈的看見落在了「百姓」身上，他們勇敢地指出：約拿單的得勝證明了他「與神一同做事」。恩典的介入打破了死板的律法。

「基督徒的領袖不是建立在權力的行使上，而是建立在對恩典的敏銳上。」—— 盧雲

講章文稿

【引言】

弟兄姊妹，今天我們要透過撒母耳記上14章，來看一位國王如何用他錯誤的熱心，差點毀了整個國家。這篇信息的主題是：「衝動的宣告與蒙蔽的領袖——跨越屬肉體的熱心」。

一、 瞎眼的熱心：被轄制的起誓

掃羅王為了個人的復仇，竟然下了一道荒謬的命令：不打贏仗不准吃飯。這看似敬虔的禁食宣告，其實是瞎眼的熱心。掃羅把信仰當成掌控軍隊的工具。提摩太·凱勒牧師說過：「宗教是：『我順服，所以我被接受。』福音是：『我被接受，所以我順服。』」

二、 失控的惡果：急躁帶來的妥協

當百姓餓到極點，非但沒有變得更聖潔，反而急躁地將牛羊連肉帶血生吃了。這就是失控的惡果！極端的律法主義最終往往導致嚴重的犯罪。潘霍華曾說：「人的律法使人成為奴隸，但上帝的恩典使人得自由。」我們不該用人為的框架去限制神的工作。

三、 沉寂的天上：當神不再說話

掃羅看見百姓犯罪，沒有反省自己的領導，反而立刻築壇，甚至求問神要不要繼續追擊。但這一次，神沒有回答他。天上陷入了沉寂。陶恕曾精準地指出：「我們常常不是在尋求神的旨意，我們只是在尋求神對我們自己旨意的批准。」當上帝向我們保持沉默時，不要急著找代罪羔羊。

四、 恩典的代求：與神同工的轉機

最後，籤抽出來了。掃羅為了顧全面子，竟然堅持要殺死自己的兒子。但這時候，真正的轉機出現了！百姓勇敢地站出來，成為了恩典的代求者。真正的屬靈看見，是認出誰真正與神同工，並勇敢地為他擋下律法主義的刀劍。

結論

放下屬肉體的「熱心」，擁抱基督的「恩典」，並有智慧地看出神在別人身上的作為，與祂「同工」。

3個關鍵字

  • 01
    熱心 (Zeal) — 需以真理引導，而非出於血氣。
  • 02
    恩典 (Grace) — 超越律法規條，帶來生命的明亮。
  • 03
    同工 (Partnership) — 放下自我中心，參與神正在做的事。

實踐行動

  • 審視誓言與承諾，檢視是否出於衝動，在神面前尋求赦免。
  • 操練安息與恩典，容許自己和同工有喘息（吃蜜）的空間。
  • 成為代禱與守望者，尋找因體制壓力灰心的同工，主動給予鼓勵。
